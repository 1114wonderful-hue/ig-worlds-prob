这个数字怎么来的？

  • 纯穷举：BO3 的 2:0 / 2:1 / 1:2 / 0:2 四种比分等概率（各 1/4），BO5 六种比分等概率。
  • 所有队伍：不仅穷举 IG 自己的比赛，还穷举登峰组 / 涅槃组每一支队伍的剩余比赛（其他队胜负直接影响全年积分排名和冒泡赛资格）。
  • 官方规则：全年积分 = 三赛段积分之和；1 号种子 = 夏季总冠军，2 号 = 积分第一（除冠军），3/4 号 = 冒泡赛。LPL 2026 共 4 个名额。
  • 零实力判断：每场比赛双方胜率 50%，不掺入任何强弱判断。
